## 驱动

[CUDA Compatibility :: NVIDIA Data Center GPU Driver Documentation](https://docs.nvidia.com/deploy/cuda-compatibility/index.html) 驱动与CUDA版本兼容性

### 方式一

禁用开源显卡驱动

```bash
sudo vim /etc/modprobe.d/blacklist.conf
```

添加

```bash
blacklist nouveau
options nouveau modeset=0
```

安装显卡驱动

```bash
sudo add-apt-repository ppa:graphics-drivers/ppa
sudo apt-get update
ubuntu-drivers devices
sudo ubuntu-drivers autoinstall
```

重启

```bash
sudo init 6
```

### 方式二

若从nvidia源下载驱动较慢，可以选择使用.run文件安装。

禁用开源显卡驱动

```bash
sudo vim /etc/modprobe.d/blacklist.conf
```

添加

```bash
blacklist nouveau
options nouveau modeset=0
```

更新内核重启（这边也可以不重启，只更新内核试试）

```bash
sudo update-initramfs -u
sudo init 6
```

`code`进入命令模式，停用桌面

```bash
sudo systemctl stop gdm3.service
```

从nvidia官网下载run文件，或者直接从ftp服务器下载

```bash
wget ftp://ftp.laocheng.tech/public/NVIDIA driver and CUDA Dev toolkit/NVIDIA-Linux-x86_64-510.54.run
```

安装显卡驱动，启动桌面

```bash
sudo sh xxx.run
```

```bash
sudo systemctl start gdm3.service
```

`code`进入桌面模式

重启

```bash
sudo init 6
```
