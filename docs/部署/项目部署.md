# 所有的项目都部署到docker中

## 后端配置文件 application.yml

在 IDEA 的右侧 Maven 面板中，双击 `Lifecycle` -> `clean`，然后双击 `package`。

- **产物**：在 `target` 目录下会生成一个 `.jar` 文件（例如 `lab-monitor-backend-0.0.1-SNAPSHOT.jar`）。
- **操作**：把它重命名为 **app.jar**（为了方便 Dockerfile 统一识别）。

```
server:
  port: 8080

spring:
  application:
    name: lab-monitor

  # 数据库连接
  datasource:
    driver-class-name: com.mysql.cj.jdbc.Driver
    # 注意：IP 是你服务器的 IP
    url: jdbc:mysql://localhost:3306/lab201_monitor?useUnicode=true&characterEncoding=utf-8&serverTimezone=Asia/Shanghai
    username: root
    password: lab201201

  # Redis
  data:
    redis:
      host: localhost
      port: 6379
      password: lab201201
      database: 0

  # RabbitMQ
  rabbitmq:
    host: localhost
    port: 5672
    username: lab201admin
    password: lab201201

  ai:
    vectorstore:
      milvus:
        client:
          host: localhost
          port: 19530
        database-name: default
        collection-name: lab201_collection
        embedding-dimension: 768
    ollama:
      base-url: http://localhost:11434
      chat:
        model: qwen2.5:7b # 确保你服务器下载了这个模型
        options:
          temperature: 0.7

mybatis-plus:
  configuration:
    log-impl: org.apache.ibatis.logging.stdout.StdOutImpl # 打印 SQL 日志

# application.yml
springdoc:
  swagger-ui:
    path: /swagger-ui.html
    tags-sorter: alpha
    operations-sorter: alpha
  api-docs:
    path: /v3/api-docs
  show-actuator: true

knife4j:
  enable: true  # 开发环境开启，生产环境建议改为 false
  setting:
    language: zh_cn

```

## 前端

**npm run build**打包前端

这会生成一个 `dist` 文件夹。**把 dist 文件夹里的所有内容**，上传到服务器的 `docker/html/dist/` 目录下。
