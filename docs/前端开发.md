## 解决刷新登录失效问题

### 插件法（本项目方法）

使用插件 `pinia-plugin-persistedstate`

#### 1. 安装插件

在终端执行：

```bash
npm install pinia-plugin-persistedstate
```

2.2. 在 `main.ts` 中注册插件

打开 `src/main.ts`：

```typescript
import { createApp } from 'vue'
import { createPinia } from 'pinia'
import piniaPluginPersistedstate from 'pinia-plugin-persistedstate' // 👈 1. 引入

import App from './App.vue'
import router from './router'
// ... 其他引入

const app = createApp(App)
const pinia = createPinia()

pinia.use(piniaPluginPersistedstate) // 👈 2. 注册

app.use(pinia)
app.use(router)
// ...
app.mount('#app')
```

#### 3. 在 User Store 中开启持久化

打开 `src/store/user.ts`，只需加一行配置：

```typescript
import { defineStore } from 'pinia'
import { ref } from 'vue'
import { login as loginApi } from '@/api/sysUser'

export const useUserStore = defineStore('user', () => {
  const token = ref<string>('')
  const userInfo = ref<any>(null)
  const role = ref<'admin' | 'user'>('user')

  const login = async (form: any) => {
    const res: any = await loginApi(form)
    userInfo.value = res
    role.value = res.role || 'user'
    token.value = 'mock-token-example' // 后续对接后端真实 Token
  }

  const logout = () => {
    token.value = ''
    userInfo.value = null
    role.value = 'user'
  }

  return { token, userInfo, role, login, logout }
}, {
  persist: true // 👈👈👈 只需要加这一行，神奇的事情就发生了！
})
```

*(注意：如果你用的是 Option Store 写法，persist: true 写在 actions 同级；如果你用的是 Setup Store 写法（如上），persist 选项作为 defineStore 的第三个参数传入)*

**验证效果：**

1. 登录成功。
2. 按 F12 -> Application (应用) -> Local Storage。
3. 你会发现多了一个 key 叫 `user`，里面的 value 是你 store 的所有数据。
4. 刷新页面，数据依然在，不再掉线！

### 手动存取法（原理最清晰）

**逻辑：**

1. 登录成功时：`localStorage.setItem(...)`
2. Store 初始化时：`localStorage.getItem(...)`
3. 退出登录时：`localStorage.removeItem(...)`

**修改 src/store/user.ts：**

```typescript
import { defineStore } from 'pinia'
import { ref } from 'vue'
import { login as loginApi } from '@/api/sysUser'

export const useUserStore = defineStore('user', () => {
  // 1. 初始化时，先尝试从 localStorage 拿数据
  const storedUser = localStorage.getItem('userInfo')
  const storedToken = localStorage.getItem('token')

  const token = ref<string>(storedToken || '')
  const userInfo = ref<any>(storedUser ? JSON.parse(storedUser) : null)
  // 角色默认值逻辑：如果有 user，就取 user.role，否则默认 'user'
  const role = ref<'admin' | 'user'>(userInfo.value?.role || 'user') 

  // Action: 登录
  const login = async (form: any) => {
    const res: any = await loginApi(form)
    
    // 2. 更新 State
    userInfo.value = res
    role.value = res.role
    token.value = 'mock-token-123' // 暂时模拟一个 Token (如果后端还没发)

    // 3. 🔥🔥 关键：存入 localStorage
    localStorage.setItem('userInfo', JSON.stringify(res))
    localStorage.setItem('token', token.value)
  }

  // Action: 登出
  const logout = () => {
    userInfo.value = null
    role.value = 'user'
    token.value = ''
    
    // 4. 🔥🔥 关键：清除 localStorage
    localStorage.removeItem('userInfo')
    localStorage.removeItem('token')
  }

  return { token, userInfo, role, login, logout }
})
```

```typescript
export function page(params: any) {
  return request<any>({
    url: '/sys-user/page',
    method: 'get',
    params  // <--- 注意这里
  })
}
```

params和data的区别

| **特性**            | **params**                        | **data**                       |
| ------------------- | --------------------------------- | ------------------------------ |
| **对应 Axios 属性** | `params`                          | `data`                         |
| **HTTP 位置**       | **URL 查询字符串** (Query String) | **请求体** (Request Body)      |
| **常用请求方法**    | **GET**, DELETE                   | **POST**, **PUT**, PATCH       |
| **URL 样子**        | `/api?id=1&name=test`             | `/api` (数据隐藏在包里)        |
| **数据量限制**      | 有限制（URL 不能太长）            | 无限制（可以传文件、大段文字） |
| **你的项目中**      | 用于**搜索、分页、筛选**          | 用于**填写表单、提交数据**     |
