| **作用**         | **旧版 Swagger 2 (不要用)** | **新版 OpenAPI 3 (请使用)**       |
| ---------------- | --------------------------- | --------------------------------- |
| **类/模块描述**  | `@Api(tags="...")`          | **@Tag(name="...")**              |
| **接口方法描述** | `@ApiOperation("...")`      | **@Operation(summary="...")**     |
| **参数描述**     | `@ApiParam`                 | **@Parameter(description="...")** |
| **实体类描述**   | `@ApiModel`                 | **@Schema(description="...")**    |
| **实体字段描述** | `@ApiModelProperty`         | **@Schema(description="...")**    |

## 接口规范

**路径规范**：所有接口统一以 `/api/v1` 开头（版本控制），资源名使用 **kebab-case**（短横线命名，如 `server-node`），而不是驼峰。

**方法规范**：

- `GET`：查询（单条、列表、分页）
- `POST`：新增 / 复杂业务操作（如上报）
- `PUT`：修改
- `DELETE`：删除

**文档规范**：全面接入 `Knife4j`，每个接口必须有 `@Operation` 说明。

**参数规范**：分页统一用 `page`, `size`，复杂查询用 POST Body 或 Query String。
